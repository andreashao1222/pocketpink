# Pocket Pink ♡

A girly, soft-pink personal spending diary.

## What it does

- Calendar homepage for daily spending
- Click any date to enter lunch, dinner, and coffee/milk tea/supermarket spending
- Daily target is ¥70 on Dad's card
- Green dates = at or under target; red dates = over target
- Shows monthly saved / over amount based on recorded days
- Separate optional pocket-money tracker
- Set a different allowance amount and date range for each half-month
- Add personal purchases with amount + note
- Warns you when less than half your allowance remains before the period is halfway over
- Saves everything in browser localStorage (no account or database needed)

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy

This is ready for GitHub + Vercel. No environment variables are required.
